# ADR-0002：域文档改为命令参考，主流程改为「读 → 改 → 验」

- 状态：接受
- 日期：2026-10-21
- 取代：ADR-0001 中的「查询路由留在 SKILL.md」与「按来源分层」

## 背景

ADR-0001 把 skill 组织成来源分层：`--help` 查参数、域文档查字段、README 校对版本。实际使用暴露三个问题：README 移除后，没有任何地方能回答「这个域有哪些命令」；查询路由只覆盖四条查询路径，其余命令没有入口；域文档按内容类型排列，读者不知道什么时候该打开它。一次会话里，agent 因此对每条命令都先跑 `--help`，并在传多行正文时临时自创 here-string。

## 决定

1. **域文档以「想做的事 → 命令」表开头**，既是命令地图也是选择依据；能力缺口写在对应命令行旁。
2. **命令发现交给 `--help`**：不知道用哪条时 `dida --help` → `dida <group> --help`；参数不确定时同理。其余域不建文档。
3. **主流程写成「读 → 改 → 验」**：先 `task get` 取现状，再 `task update`，再 `task get` 复核；`task.md` 附一个含多行正文的完整示例。
4. **删除独立的来源分层小节**：版本判定与 README 路径并入前置检查，全 skill 只此一处。

## 后果

- `SKILL.md` 变短，域文档变长；命令地图可能随新版本漂移，由前置检查的版本比对兜底。
- 「查参数去 `--help`」仍然成立，但不再需要一个专门章节来陈述。
